# 幼神 · 第八天以后

独立的《幼神 Demo》续玩 Mod，版本 **1.0.1**。从第八天开始继续尚未触发的随机直播内容，并把原本的洪水简报和 Demo 收束推迟到补充直播结束后。

## 游戏中的变化

第 1～7 天沿用原流程。从第 8 天开始，每天进入补充直播日，日期继续增长，沿用游戏的角色连线卡片、原剧情、选项和资源结算。补充直播期间不运行 Day8 及之后的强制主线、新闻日程、晨间和夜间闲聊。当天时间到 18 点后可以进入下一天，剩余事件继续保留。

补充直播日会在原生简报里显示实际日程说明。新闻页面保留换日前已经发布的最近版面，并明确标注本日无新增；若载入的旧存档没有保留新闻正文，则显示无新增及无历史版面的说明，不补造新闻。收束时才正式发布延后的原版新闻。

仅使用原作时，目录包含 **21 个随机入口、31 个实际事件变体**。实际目录根据当前启用 Mod 合并后的 Yarn 自动生成，使用 `Live_Entry_*` 常规连线入口的新角色会一起纳入续玩。它包括角色后续事件和一次性的次要角色事件，不把对话内部的提问、选项、技能判定结果当成另一场直播；原作 Storage、Day30、ForShot 等开发遗留内容不主动加入。

允许补看已经错过的日期窗口、时段，以及受每天连线次数限制的事件。前序事件、角色状态、入群/任务状态和互斥选择仍然有效。例如，菲利克斯的后续去向取决于此前的选择，不会把四个互斥结果都安排进同一存档。

当没有满足剧情前置的未见事件时，游戏会提示本分支的补充直播已经完成。可以留在桌面查看进度，或者选择结束；选择结束后才发送延后的洪水新闻与简报，再进入原生 `NormalEnd` 结束界面。完成标志随当前存档保存，不会依靠不断增加空白天数来等待不可能出现的事件。

## 安装

1. 关闭游戏，将发布 ZIP 解压到任意目录。
2. 在解压后的安装包目录打开 PowerShell，运行：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\Install-Mod.ps1 -GamePath 'B:\Steam\steamapps\common\幼神 Demo\Build'
   ```

   如游戏安装在其他位置，把 `GamePath` 改为包含 `Aistalt.exe` 的目录。

3. 启动游戏，在 **设置 → Mod 管理器** 中启用 **幼神·第八天以后**，然后重新载入存档。
4. 第八天开始自动接入补充直播。在游戏桌面打开**开始菜单 → 续玩进度**，查看已触发、当前可触发和受到剧情条件限制的事件；窗口中的**关闭**按钮返回游戏。

1.0.1 将入口放进原生开始菜单，并改用原生 FGUI 进度窗口、按钮和滚动列表。安装多存档管理 Mod 时，“续玩进度”排在“普通保存”后面，保留原生快存/快读位置。

可以和资料终端、弹幕 Mod 同时安装。此项目使用自己的插件目录、原生 Mod 目录和安装记录。已存在的 BepInEx 5 会直接复用；没有加载器时，安装包提供 BepInEx 5.4.23.5 x64。

已有存档直接使用游戏的事件访问记录。显式副标题按 `title.subtitle` 精确识别；没有副标题的单一事件组兼容旧编译哈希记录。多变体组不会因为基础标题已经出现过就被整组略过。请从第八天结束演出前的存档继续；已经进入原游戏结束界面的会话需要先回到菜单读档。

## 新角色 Mod 兼容

目录读取游戏按启用状态与载入顺序合并后的实际节点。遵循原作 `Live_Entry_角色名`、`Character: 角色定义名` 和固定 `<<jump 事件组>>` 约定的 Mod 会自动加入；直接把正文写在连线入口中的 Mod 也可以识别。角色原有的 `when` 剧情条件仍交由游戏 Yarn 执行，只有明确写出的 `$Today`、`$CurrentHour`、`$CurrentMinute`、`$LineCount` 和 `$Minor_Token` 排期条件会放宽。自定义函数内部的规则保持原样。

本 Mod 不覆盖其他角色 Mod 的文件。它在游戏自己的合并编译阶段，单独生成临时的续玩条件；角色内容、启用状态、载入顺序或兼容配置改变后，会沿游戏的重新载入流程重建目录。新安装的角色产生可达事件时，已经收束的续玩存档也会重新开放，“续玩进度”窗口中可以点击“继续匹配未见事件”。已经处于原结束界面的会话仍需先读档。

特殊 Mod 若使用其他入口前缀，或入口中含多个可能的跳转，可以编辑游戏目录中的 `BepInEx/config/graywill.infantgod.afterdemo.cfg`，例如：

```ini
[Compatibility]
AdditionalEntryPrefixes = CustomLive_,DLC_Live_
EntryTargets = {"CustomLive_MyCharacter":"MyCharacter_Story"}
```

`EntryTargets` 明确指定一个入口对应的事件或事件组。入口仍需提供原作卡片系统要求的 `Character` 头。修改后在游戏中重新载入 Mod 并读档。不能自动识别的特殊入口会列在“续玩进度”窗口中，不会静默当成已经完成。

## 卸载与停用

关闭游戏后，在同一发布包目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\Uninstall-Mod.ps1 -GamePath 'B:\Steam\steamapps\common\幼神 Demo\Build'
```

卸载只移除本 Mod 的插件和脚本，并恢复首次安装前存在的同名文件。共用 BepInEx 加载器、其他 Mod、存档和备份保留。在游戏 Mod 管理器中停用本 Mod 后，请回到菜单重新载入原流程存档；续玩中的新增节点属于本 Mod。

安装和卸载脚本不会编辑存档。游玩时，原事件自然产生的状态与访问记录会随正常游戏存档保存。

## 源码与构建

需要 .NET SDK、Python 3.9 或更新版本，以及已经安装的《幼神 Demo》。在源码目录执行：

```powershell
.\build.ps1 -GamePath 'B:\Steam\steamapps\common\幼神 Demo\Build'
```

构建会从已安装游戏读取授权脚本，生成原作事件的中文显示辅助资料，然后编译插件。实际事件目录和保留剧情前置的 Yarn 条件在游戏合并当前启用的 Mod 后动态生成。构建输出：

- `dist/InfantGod-AfterDemo-v1.0.1/`：完整安装包目录。
- `dist/InfantGod-AfterDemo-v1.0.1.zip`：可分发安装包。

游戏的 InfantGod、Unity、Yarn Spinner 等程序集仅用于编译引用，不进入交付包。首次准备 BepInEx 构建依赖时会从官方 GitHub 下载，已缓存后不需要重复下载。

主要实现：

- `tools/build_catalog.py`：从原作随机入口生成中文显示辅助资料，不作为角色白名单。
- `src/RuntimeCatalog.cs`：读取合并后的角色 Mod，自动发现入口与变体并生成原生条件。
- `src/ScheduleConditions.cs`：拆分排期条件和剧情条件，保留自定义业务函数。
- `native-mod/InfantGodAfterDemo/Yarn/`：补充直播、结束日程和延后简报。
- `src/EventCatalog.cs`：运行时精确节点映射、旧访问记录识别、条件判定。
- `src/Patches.cs`：仅在本 Mod 启用且日期达到第八天时接管入口与日程跳转。
- `src/AfterDemoHost.cs`：持久宿主、原生命令绑定和事件路由。
- `src/MenuIntegration.cs`、`src/ProgressWindow.cs`：原生开始菜单入口与进度窗口。

已根据当前游戏脚本和程序集确认随机候选生成、精确变体名、日期推进、Mod 合并与缓存入口，并完成插件定向编译。针对“移除排期时会不会删除剧情前置”做过一次最小表达式检查，覆盖日期与前序事件混合、否定日期、每日冷却与互斥路线、候选数量与任务条件、字符串内注释符号。
