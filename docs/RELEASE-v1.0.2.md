# 幼神·第八天以后 v1.0.2

独立的续玩 Mod。从第八天起继续尚未触发的随机直播事件，并在当前分支可达内容完成后进入延后的原版收束。

- 补看错过日期和时段的事件，同时保留剧情前置、角色状态和互斥选择。
- 动态识别已启用的新角色 Mod；开始菜单“续玩进度”显示已触发、可触发及条件受限的事件。
- 补充直播日提供原生简报，右侧新闻继续使用原作随机池生成，同日读档保留已生成的结果。
- 使用原生菜单、窗口、按钮和滚动条，修复新增菜单条目后的裁切及收起问题。

下载 **InfantGod-AfterDemo-v1.0.2.zip**，退出游戏后解压，在其中的安装包目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\Install-Mod.ps1 -GamePath 'B:\Steam\steamapps\common\幼神 Demo\Build'
```

启动游戏，在“设置 → Mod 管理器”启用“幼神·第八天以后”，再载入存档。可以从第八天结束演出前的存档继续。卸载使用同目录的 `Uninstall-Mod.ps1`，保留已有存档。
